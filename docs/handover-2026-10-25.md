## What is implemented

- Postgres application persistence and awaited transactions; guarded migration,
  SQLite import rehearsal and branch verification. SQLite remains an
  import/rollback source, never a runtime fallback.
- Household schema/membership expansion, session-bound household selection,
  cross-household request and mutation enforcement, scoped profiles, plans,
  groceries, prep, feedback, links, photos, settings and shared-state operations.
  Existing ambiguous/null-owned legacy state is quarantined rather than adopted.
- Public library lists/details and anonymous navigation, with private household
  payloads, feedback, photographs and mutation controls kept separate.
- Existing-account email-link continuation through self-managed Better Auth:
  expiring one-use provider links, persistent throttling, context-correct session
  establishment, replay refusal, delivery failure/retry and deletion cleanup.
- Tokenless household email associations: owner add/resend/revoke, optional
  display/relationship labels, verified recipient accept/decline and explicit
  multiple-household selection. Acceptance never moves profiles or merges data.
  Legacy invitation acceptance remains compatible.
- Code-free household creation for verified accounts with no membership:
  automatic management permission, locked session selection, own-profile
  continuation, validation, retry and duplicate/expired/unverified refusal.
  This does **not** make new-account signup self-service.
- Hydration-safe profile/plan/household forms and grocery/pantry/manual/prep
  mutations. Browser cases deliberately delay scripts and prove first-change
  persistence. Cross-session checklist cases await actual action responses.
- Private state snapshots/publication/recovery, encrypted backup/vault operator
  tooling and reminder scheduling/device-receipt foundations have local
  coverage. Their live provider/device/recovery acceptance remains separate;
  none is silently enabled by the merge.
- Protected preview provisioning, explicit preview migration/library-seed
  commands, exact-SHA CI deployment gates, runtime/schema drift refusal,
  fixed auth-origin alias and retained read-only hosted Playwright smoke.
