# Recipe photos

Put photos here and reference them from a recipe with `"image": "palak-paneer.webp"`.

- Use only photos you took or have a licence for. Set `image_credit` when the licence asks for attribution.
- Landscape, 1600 px wide or less, under 300 KB each (WebP preferred). The app crops to 4:3 on cards.
- A recipe without a photo is valid. The UI shows a typographic card with the macro bar.
